# Security Policy

## Supported Versions

Security fixes are applied to the latest `main` branch state.

## Reporting a Vulnerability

Please do not open public issues for suspected vulnerabilities.

Report security issues through GitHub Security Advisories for this repository. Include:

- A clear description of the issue.
- Impact and attack preconditions.
- Steps to reproduce.
- Any suggested mitigation.

You can expect an initial acknowledgment within 5 business days.

## Disclosure Expectations

- Give maintainers reasonable time to investigate and patch.
- Avoid public disclosure until a fix or mitigation is available.
- Coordinate on release timing for high-impact findings.
